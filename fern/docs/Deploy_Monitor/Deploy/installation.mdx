# Installation

Learn how to install and set up Mark.

## Prerequisites

Before you begin, make sure you have:

- Git installed
- Node.js 18
- A GitHub account

## Clone the Repository

```bash
git clone https://github.com/Utkarshnegi2k5/Mark.git
cd Mark
```

## Install Dependencies

```bash
npm install
```

## Start the Development Server

```bash
fern docs dev
```

Open your browser and visit:

```
http://localhost:3000
```
