The **User Management** section allows administrators to create, view, update,
and deactivate user accounts.

## Overview

Administrators can perform the following actions:

- Create new users
- View user details
- Edit user information
- Assign roles
- Change account status
- Deactivate or delete users

## User List

The user table displays:

| Field | Description |
|---|---|
| Name | User's full name |
| Email | User's email address |
| Role | Assigned role |
| Status | Active, inactive, or suspended |
| Created | Account creation date |
| Actions | Available management actions |

## Creating a User

To create a new user:

1. Open **User Management**.
2. Click **Add User**.
3. Enter the user's name and email address.
4. Select a role.
5. Click **Create User**.

<Callout type="info">
  New users may receive an email invitation to set their password.
</Callout>
